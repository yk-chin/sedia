description: 把产品想法锚定到联合国 SDG 的 Goal → Target → Indicator 三层，并用马来西亚本地数据做基线和影响估算。当用户提到 SDG 对齐、影响量化、评委会问影响时使用。
---

联合国 SDG 有三层：Goal（17 个）→ Target（169 个，编号如 11.2）→ Indicator（231 个，编号如 11.2.1）。

绝大多数队伍只说到 Goal 层，那是 25 分里的 12 分。要做到：

1. 选定 1 个 Primary Goal（限 SDG 3 健康 / SDG 4 教育 / SDG 11 可持续城市），最多 1 个 Secondary。
2. 定位到具体 **Target 编号**，写出 Target 原文。
3. 定位到对应 **Indicator 编号**，写清楚我们的产品如何改善这个指标。
4. 找马来西亚本地基线数据，优先顺序：
   - OpenDOSM / data.gov.my（马来西亚统计局开放数据）
   - 相关部委年报（卫生部 / 教育部 / 地方政府部）
   - 世界银行、WHO、UNESCO 的马来西亚国别数据
   每个数字必须写明【来源 + 年份】。找不到就明说"未找到，改用区域代理指标"。

5. 产出影响估算式：

```
基线：马来西亚每年约 [X] 人受 [问题] 影响        ← 来源、年份
可触达：其中 [Y]% 属于我们的目标用户             ← 假设 + 理由
干预效果：单用户改善 [Z] 单位                    ← 假设 + 理由
──────────────────────────────
年影响 = X × Y × Z = [结果]
对应 Indicator [编号] 的改善幅度约 [%]
```

6. 最后必须写一行诚实声明：
   「本估算基于 3 项假设，其中最不稳固的是 ⟨哪一项⟩，因为 ⟨理由⟩。」

**不要编造数据。** 找不到就标注为未验证，并说明现场该怎么向评委解释。
